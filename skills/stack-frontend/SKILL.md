# Set up the frontend

Choose one recipe per application:

- For `tanstack-start`, read [TanStack Start setup](references/tanstack-start.md).
- For `nextjs`, read [Next.js setup](references/nextjs.md).
- For `react`, read [React with Vite setup](references/react.md).
- For `svelte`, read [SvelteKit or standalone Svelte setup](references/svelte.md).

TanStack Start and Next.js include React. Keep routes, server entrypoints, and components in the framework's expected locations.

Read the recipe's official setup source before running its generator. Commands use npm syntax. Translate them to the selected package manager. If the destination contains project files, generate into a temporary directory and merge the result.
