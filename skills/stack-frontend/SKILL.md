# Set up frontend

Choose one recipe per application. TanStack Start and Next.js already include React. Keep routing, server functions, and component files in their framework's expected locations. Put business policy in the selected architecture's modules.

- Read [TanStack Start](references/tanstack-start.md) for a React full-stack app with TanStack Router.
- Read [Next.js](references/nextjs.md) for a React full-stack app with the App Router.
- Read [React](references/react.md) for a standalone client with Vite.
- Read [Svelte](references/svelte.md) for SvelteKit or a standalone Svelte client.

Read the linked official page before running a generator. The examples use npm, and must be translated to the project's selected package manager. Run generators in a temporary directory when the destination already contains template files.
